网页归档助手 - 设置

Obsidian 连接设置

请确保已在Obsidian中安装并启用 Local REST API 插件

在Obsidian的 Local REST API 插件设置中找到 API Key
默认端口: 27124

归档设置

笔记将保存在此文件夹下，留空则保存在根目录
可用变量: {{title}} 页面标题, {{date}} 日期, {{time}} 时间, {{url}} URL, {{site}} 网站名

使用说明

1. 安装 Obsidian Local REST API 插件

在Obsidian的社区插件市场中搜索并安装 "Local REST API" 插件

2. 启用插件并获取API密钥

启用插件后，在设置页面找到 API Key，复制到上方的输入框

3. 使用方式

  • 点击插件图标 - 打开弹出窗口，选择归档方式
  • 右键菜单 - 在页面上右键选择归档选项
  • 选择区域 - 点击"选择区域归档"后在页面上点击选择
